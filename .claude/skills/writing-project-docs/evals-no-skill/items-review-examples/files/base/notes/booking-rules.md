# Booking rules to add

## How many bookings a member can hold

Each member can have at most 3 upcoming bookings, so nobody hogs the rooms. For example, Priya
has 3 bookings next week, so she can't book a fourth. She can still grab a room for later today,
though, since bookings for the same day don't count toward the 3.

## Checking in

The organizer checks in once their meeting starts. Check-in stays open until the time slot ends.
For example, for a 14:00 booking, the last moment to check in is just before 14:30.

## Confirmation emails

We email the organizer a confirmation for each booking they make, unless they've turned emails off
in their settings.
