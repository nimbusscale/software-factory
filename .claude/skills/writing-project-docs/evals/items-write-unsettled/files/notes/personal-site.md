# Personal site app: notes

These are notes for a self-hosted personal site: a résumé, a portfolio and a place to write, all in
one. One person owns each site. Nothing is built yet.

The owner writes their content once: jobs, projects, talks and posts. Each item is public or
private. A private item is shown only to the owner.

Different audiences want different things. A recruiter wants jobs and skills. A conference
organiser wants talks. So the site has views: each view shows the same content differently. Each
view has its own address, such as `/recruiter`, and is made of sections, such as Experience or
Talks.

Content selection is explicit. A section can follow all eligible public content or show selected
items. An empty manual selection stays empty. Opening or saving a view never quietly broadens what
it publishes.
