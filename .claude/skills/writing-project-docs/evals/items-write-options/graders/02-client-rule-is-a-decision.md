A decision, an item with an `AD` or a `TD` ID, says the client holds no rules logic of its own
beyond what it needs to show a player their options. It can say this in any words, and can be part
of a decision that says what the client does. It fails if this rule is missing, or is only in a
technical requirement (`TR`) or a term.
