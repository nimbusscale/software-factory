No item settles whether the client uses the engine to show a player their options, such as where a
tile fits. This is false only if an item, term or Why says the client uses, runs, shares or gets
that logic from the engine, says it must, or says it must not. It's also false if an item copies the
notes' open wording, such as "the client may use the engine".

These don't settle it, so they're fine: an item that says the client holds no rules logic of its
own beyond what it needs to show options, an item that says all game rules live in the engine, and
items that say the server uses the engine.
