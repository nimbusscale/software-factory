# Booking rules to add

This first version is for our office of 20 to try out for a month. It only needs to be good
enough for that. Getting the rules right matters more than polish.

## How many bookings a member can hold

Each member can have at most 3 upcoming bookings. Bookings for the same day don't count toward
the 3.

## Checking in

The organizer checks in once their meeting starts. Check-in stays open until the time slot ends.

## Confirmation emails

We email the organizer a confirmation for each booking they make.
